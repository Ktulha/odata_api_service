## Ключевые изменения

### `src/odata_cache/filter_dsl.py` (новый)
Парсер подмножества OData `$filter`, смешанный стиль (решение Q4-a):
- sugar-операторы: `=` `<>` `>` `<` `>=` `<=` `~` (подстрока без регистра);
- канонические: `eq ne gt ge lt le in like and or not`, `is null / is not null`;
- функции: `contains() startswith() endswith()`, `in [..]` со списком литералов;
- вывод: AST с типизированными литералами (guid/datetime/number/string/bool),
  ошибки с позицией в строке; лимиты: длина ≤ 2000, глубина ≤ 8.
Безопасность: никакого eval, только AST → параметризованный SQL на следующем шаге (7.2).

### `src/odata_cache/load_plan.py`, `entity_resolution.py`, `services/access.py`, `registry_service.py`
Ленивая загрузка и каскад разрешённых подчиненных сущностей; алиасы/подмены целей ссылок.
